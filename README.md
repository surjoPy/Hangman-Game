# Hangman Game

A console-based Hangman game built using Python.

Players choose a category and attempt to guess the hidden word before running out of lives. The game randomly selects words, tracks guessed letters, validates user input, and provides feedback after every guess.

## Features
- Random word selection
- Multiple categories
- Lives system
- Letter tracking
- Input validation
- Duplicate guess detection
- Replay functionality

## Technologies Used
- Python
- Random module
- Console interface
